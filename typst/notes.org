* General Info

Typst is a markup like typsetting system written in Rust.

* Webpage

** General

https://typst.app/

** Github

https://github.com/typst/typst

* Text formatting
** Headings

`= H1`

`== H2`

`==== H3`

etc.

** Lists
*** Numbered

`+ Intem 1`

`+ Intem 2`

`+ Intem 3`,

etc.

*** Bulleted

`- Item 1`,

`- Item 2`,

`- Item 3`,

etc.

** Emphasis
*** Italics

`_italicized text_`

*** Bold

`*bold text*`

*** Underline

`#underline[underlined_text]`

** Raw

You may use raw text with verbatim mono-space font and optional syntax
highlighting (useful for code snippets).

*** Examples

For inline code `snippet`.

For code block:

#+BEGIN_QUOTE

```rust
fn main() {
    println!("Hello World!");
}
```
#+END_QUOTE

Constructing the element prgrammatically:

#+BEGIN_QUOTE

#raw("fn " + "main() {}", lang: "rust")

#+END_QUOTE

which will give:

#+BEGIN_QUOTE

fn main() {}

#+END_QUOTE
