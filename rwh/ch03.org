* Defining Types, Streamlining Functions
* Defining New Data Type

#+begin_src

data BookInfo = Book Int String [String] deriving (Show)
-- Book iD title authors

#+end_src

'BookInfo' - name of new type (a type constructor)
'Book' - name of a value constructor

value constructor and type constructor often have the same name

Once new type was defined we can inspect it in GHCI

#+begin_src

:t BookInfo
-- or
:t Book 1 "title" ["author 1", "author 2"]

#+end_src

* Type Synonyms

#+begin_src

type CustormerID = Int
type Name = String

-- which can now be used in

data Customer = Customer CustomerID Name

#+end_src

* Algebraic Data Types (ADTs)

#+begin_src

data Bool = False | True
-- a type with two value constructors
-- it can be either (| - or) one of the value constructors

#+end_src

* ADTs vs Tuples

ADTs allow to distinguish between otherwise identical pieces of information,
e.g.

#+begin_src

type CustormerID = Int
type Name = String
data Customer = Customer CustomerID Name

customer = Customer 2 "John Smith"

-- vs

customer = (2, "John Smith")

#+end_src

The above properties of ADTs help to reduce the number of mistakes in the code.
